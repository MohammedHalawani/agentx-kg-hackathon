## Gaps to fix

- V3.2 lifecycle fields are missing from the TypeScript wire/domain models and UI. Existing execution status fallback can mislabel rejected/failed responses as transport failure.
- Waiting cases require bounded detail enrichment; queue rows cannot establish acknowledgement, acceptance, evidence receipt or resolution. Current queue reads use `scope=all`; switch to separately paged active/resolved scopes and retain bounds/truncation reporting.
- Watched waiting cases need detail refresh even when acknowledgement does not increment the case version. Bound and deduplicate these reads.
- Local selection resets incompletely across cases (narration highlight/photo/dialog state can persist). Key the complete workspace by case ID; close stale streams, ignore closed-stream callbacks and refuse stale detail snapshots.
- Existing worker cards are on Operations; add a compact selector in the investigation workspace using actual active claims and capacity. Availability must come from worker status, not elapsed time or case status.
- Preserve one existing collapsible operations rail, adding Waiting/Resolved tabs rather than another permanent sidebar. Both tabs link to the same workspace.
