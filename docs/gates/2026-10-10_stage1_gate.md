## What was built

- `chat/world/`: a two-layer simulator. A private physical simulation (each parcel in one place at a time) and a separate
  observation layer that writes evidence with the time it happened and the time Suhail received it. 25 fault mechanisms act
  on whatever they physically touch: a driver's route, a clerk's shift, a reader, a label batch, a scale, a truck, a hub.
- Export in the existing bundle format, so the import, provider feed, gateway and monitor run on it unchanged. Contract
  changes are additive, and the S5 dataset regenerates byte-identical (tested).
- Database `shipments-v2-world-1-small`; no other database was written.
- Truth labels and the simulator's physical state live outside the repository (`C:\Projects\suhail-eval-truth\`); a test
  checks that no runtime module names those paths.

## Known limits (documented, not blocking)

1. Fault density is above reality: 54% of live shipments need an answer. This is scenario weighting so that each mechanism
   appears at all in 254 live shipments; the rate is fixed in `chat/world/config.py` and recorded in the manifest.
2. Clean single-cause cases are 0 to 6 per mechanism at this size. The Stage 3 evaluation needs about 150 identifiable
   ambiguous cases; the measured yield is 95 per 254 live shipments, so an evaluation world of about 1,000 shipments
   (400 live) is the demonstrated need for a larger world. It will be generated from a fresh seed in Stage 3, not now.
3. A live shipment's booking records are in the database from the start, stamped with the booking time (as in S5). The
   tools hide a shipment until its booking time; changing the import needs the gateway to accept new bookings.
4. Five mechanisms rarely open a clean case under today's monitor rules (for example a missed connection without a plan
   breach). Consolidation is thin at this volume (median 2 parcels per container).
5. The existing investigation tools cannot yet reach other shipments' records, shared records or customer messages. About
   42% of the discriminating evidence visible at opening is out of their reach. This is Stage 2's job.
